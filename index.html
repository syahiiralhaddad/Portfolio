5G Traffic Classification with Explainable AI

View on GitHub

1Problem

5G networks carry traffic from many service classes, and operators need to classify it accurately. Black-box models are hard to trust when nobody can see why a prediction was made.

2Approach

A stacking ensemble with KNN, SVM and Random Forest as base learners and Logistic Regression as meta-learner. LLM-based feature explanations make each prediction readable, and time series analysis compares weekday and weekend traffic.

3Tools

An interactive Flask dashboard with live training progress, temporal analytics and XAI insights.

Bandwidth Optimization for Cisco SD-WAN

View on GitHub

1Problem

Bandwidth allocated to corporate SD-WAN sites often doesn't match actual usage, wasting capacity at some sites and congesting others.

2Approach

Lag, rolling and utilization features engineered from throughput patterns. A Random Forest tuned with time-series cross-validation recommends allocation per interface, while SARIMAX forecasting and 4-level threshold detection flag usage spikes.
